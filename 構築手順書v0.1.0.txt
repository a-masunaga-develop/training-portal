========================================
AWS_DEPLOY_PHASE1.txt
研修ポータル MVP AWS公開手順
========================================

目的

ローカルで動作しているMVPをAWSへ公開する。

対象機能

・Dashboard
・Phase1
・Test
・Report
・Admin

公開後にURLでアクセスできる状態にする。

========================================
Phase1方針
========================================

まずは最小構成で公開する。

構成

Internet
↓
CloudFront（Amplify）
↓
Next.js
↓
DynamoDB

まだ導入しないもの

・API Gateway
・Lambda
・Cognito
・WAF
・Claude API

まずは利用可能にすることを優先する。

========================================
Step7 環境変数設定
========================================

Amplify

Environment Variables

----------------------------------------

登録

APP_ENV=prod

AWS_REGION=ap-northeast-1

USERS_TABLE=users

REPORTS_TABLE=reports

TESTS_TABLE=tests

PROGRESS_TABLE=progress

TEST_RESULTS_TABLE=test_results

========================================
Step8 DynamoDB接続切替
========================================

ローカル

APP_ENV=local

DYNAMODB_ENDPOINT=http://localhost:8000

----------------------------------------

本番

APP_ENV=prod

AWS_REGION=ap-northeast-1

----------------------------------------

実装例

if (APP_ENV === "local")

↓

DynamoDB Local

else

↓

AWS DynamoDB
