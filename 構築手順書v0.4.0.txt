# Training Portal v0.4.0 開発計画

## 概要

v0.4.0では、v0.3.0で構築した「コンテンツ単位の学習管理システム」をベースに、AIを活用した学習支援機能を実装する。

本バージョンの目的は、研修担当者による問題作成負荷を削減し、受講者ごとの理解度を可視化することである。

v0.4.0から研修ポータルは単なるLMSではなく、AI駆動型LMS（Learning Management System）へ進化する。

| 項目 | 結果 | 確認内容 |
|---|---|---|
| 字幕自動取得 | 🔄 方式変更 | 公式の方法では他者の動画の字幕を取得できないため、管理者が字幕・教材テキストを貼り付ける方式に変更（実装メモ参照） |

| AI学習推薦 | ✅ | 受講可能なコンテンツのみ推奨。弱点に合わせて復習を提案 |
| AI管理レポート | ✅ | 人数はコードで集計、文章は氏名で記述（受講者IDを出さない）（約8秒） |
| Claude API連携 | ✅ | claude-opus-5-5、構造化出力、server-side fallback。本番は SSM からキーを取得 |
| DynamoDB連携 | ✅ | ai_generation_jobs / recommendations を AWS に作成。実行履歴・分析結果を保存 |
| AWS公開 | ✅ | main マージ後の Amplify ビルド9（コミット a5ee72b）が成功 |

# 実装メモ（実際の構成）

## 計画からの変更・補足

```text
字幕取得       他者の YouTube 動画・AWS Skill Builder の字幕は公式の方法で自動取得できないため、
               「コンテンツ本文」＋「管理者が貼り付けた字幕・教材テキスト（transcript）」を元に生成する。
               YouTube は動画ページの「文字起こしを表示」からコピーできる。

構成           EventBridge + Lambda は使わず、Next.js の Route Handler から Claude API を直接呼ぶ。
               Amplify はストリーミングとレスポンス後の処理に非対応のため、
               テスト生成は「学習ポイント抽出」「問題生成」の2回の呼び出しに分けて1回の処理時間を短くする。

モデル         Claude Opus 5.5（claude-opus-5-5）。環境変数 CLAUDE_MODEL で変更可能。
               安全分類器に拒否された場合は server-side fallback（fallbacks: "default"）で自動再実行。
               出力は構造化出力（JSON スキーマ）で受け取り、内容をコード側で検証する。

API キー       本番：SSM パラメータストア（SecureString）/training-portal/anthropic-api-key
                     環境変数 CLAUDE_API_KEY_PARAMETER にパラメータ名を設定
               ローカル：frontend/.env.local の ANTHROPIC_API_KEY（コミットしない）

理解度分析・学習推薦
               1回の呼び出しでまとめて実行し、recommendations テーブルに保存。
               受講者はダッシュボードから実行（10分に1回まで）、管理者は受講者ごとに実行可能。
               推奨コンテンツは受講可能なものだけに絞り込む。

管理レポート   人数（完了・順調・遅延・未開始）はコードで集計し、AI は文章（全体の状況・共通課題・
               フォローが必要な受講者・対応案）だけを作る。遅延＝最後の学習から7日以上。

AI設定         設定値は環境変数で管理し、画面では状態・モデル・今月の利用量（トークン・費用の目安）・
               実行履歴を表示する。
```

## 画面

```text
/                              ダッシュボードに「AI学習サポート」（おすすめ教材・次の推奨・最近の弱点・理解度分析）
/admin/contents/[contentId]    下部に「AIテスト生成」（字幕貼り付け → 学習ポイント抽出 → 問題生成 → 確認・編集 → 登録 / 再生成）
/admin/ai                      AIテスト生成（コンテンツ一覧・字幕と問題の登録状況）
/admin/ai/report               AI管理レポート
/admin/ai/analysis             AI理解度分析（受講者一覧・分析の実行）
/admin/ai/settings             AI設定・利用状況・実行履歴
/admin/students/[userId]       受講者の AI 理解度分析
```

## DynamoDB テーブル

```text
ai_generation_jobs  jobId（type / status / model / トークン数 / エラー / 出力）
recommendations     userId（理解度・弱点・推奨コンテンツ・アドバイス）
contents            transcript 属性を追加
```

## AWS 反映手順

1. admin ユーザーで Claude API キーを SSM に登録

```text
Systems Manager → パラメータストア → パラメータの作成
  名前     : /training-portal/anthropic-api-key
  タイプ   : SecureString（KMS キーは aws/ssm のまま）
  値       : Claude Console で発行した API キー
  リージョン: ap-northeast-1
```

2. admin ユーザーで IAM ポリシーを更新

```text
TrainingPortalDynamoDBAccess（コンピューティングロール）
  → infrastructure/iam/amplify-compute-role-policy.json
    （AI 用テーブル2つ、UpdateItem、SSM パラメータの読み取りを追加）

TrainingPortalDeveloper（develop-group）
  → infrastructure/iam/training-portal-developer-policy.json
    （AI 用テーブル2つを追加）
```

3. テーブル作成と環境変数（develop ユーザー）

```powershell
& "C:\Program Files\Git\bin\bash.exe" ./infrastructure/dynamodb/init.sh --aws
```

```text
Amplify 環境変数に追加
  CLAUDE_API_KEY_PARAMETER=/training-portal/anthropic-api-key
```

4. feature/ai-learning → develop → main にマージ（Amplify が自動ビルド）
